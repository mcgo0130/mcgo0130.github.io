5 Elements

Input
A HTML element that is found under a form and usually connected to a label element. An input can come in many forms and is generally used to collect info from the user.
Anchor
A HTML element that redirects users to different pages, websites, or areas on a page using it's hyper refrence atrribute.
Table
A HTML element used to organize information in a neat table format. Consists of a table head with a table row inside with headings in that, then a table body with table rows and table data cells.
Image
A HTML element that uses a source attribute to display an image found usually in the file. An alt text is usually found alongside which gives a text format to the image for accessibility.
Select
A HTML element that is found in a form that displays a drop down menu to select an option.
